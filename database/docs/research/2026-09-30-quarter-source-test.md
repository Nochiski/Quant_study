## 4. 판단

- 키움은 탈락, 네이버는 WISE 와 같은 데이터를 비공식 경로로 받는 것이라 이득이 없다(표시 오류 1건은 오히려 네이버 쪽).
- **권고: WISE 분기 화면 수집 추가** — 이미 운영 중인 수집기에 커버 종목당 1콜(`cF3002 frqTyp=1`, 하루 ≈800콜, 현재 WISE 일
  ≈19,200콜의 +4%). 파서·stage 형식이 연간과 같다. 3개월 값·원화 환산·분기별 기준 라벨을 준다.
- KIS 는 공식 API 라는 장점으로 **검산·예비 원천**(누적 → 차감, 0 = 결측 처리 필수).
- 한계: WISE·네이버·KIS 모두 **지금 시점의 최근 5~6분기만** 준다. 우리 원장이 매일 `fetched_date` 로 쌓으면 오늘부터 시점 이력이
  생기지만, **과거 백테스트용 이력은 DART 뿐**이다. 연구·백테스트는 DART, 실시간 모델은 WISE 분기(+DART 검산)로 나누는 안.
- 착수 전 수집 계획(호출 예산·원장 표·stage 규칙·건전성·모델 입력 우선순위·기준 섞임 규칙)을 먼저 쓴다.
