# 정동민 유저 스토리

퀀트는 잘 모르는 국내 주식 개인 투자자다([페르소나](../personas.md#정동민-dm)). 쉬운 말과 AI
도움으로 자기 투자 감을 규칙으로 바꾸고 결과를 이해하는 것이 이 사람의 여정이다.

### US-DM-01 AI 공급자를 한 번 연결해 둔다

> 정동민으로서 설정 화면에서 AI 공급자를 한 번만 연결해 두고 싶다. 그래야 전략 화면에서 모르는
> 것을 바로 물어볼 수 있다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: 설정 · AI 공급자
- e2e:
  - `frontend/e2e/assistant.workflow.spec.ts` :: 설정에서 공급자를 등록하면 활성이 되고 키는 꼬리 4자리만 남는다

수용 기준

- Given 등록된 공급자가 없는 설정 화면, When 표시 이름과 API 키를 넣고 "연결 테스트 후 저장"을
  누르면, Then 그 이름의 카드가 생기고 "활성" 배지가 붙는다.
- Given 방금 저장한 공급자, Then 카드에는 키의 끝 네 자리만 보이고 키 입력칸은 비어 있으며 화면
  어디에도 키 원문이 없다.
- Given 저장된 공급자 카드, When "연결 테스트"를 누르면, Then "연결 확인됨"이 보인다.

### US-DM-02 모르는 말을 전략 화면에서 바로 묻는다

> 정동민으로서 전략 화면을 떠나지 않고 "모멘텀 전략이 뭐야?" 같은 질문을 하고 싶다. 그래야 따로
> 검색하느라 흐름이 끊기지 않는다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: AI 어시스턴트 · 사이드바 대화
- e2e:
  - `frontend/e2e/assistant.workflow.spec.ts` :: 사이드바 질문에 답이 스트리밍되고 새로고침해도 이력과 진행 중 턴이 이어진다

수용 기준

- Given 공급자가 연결된 전략 화면, When "AI 어시스턴트"를 펼치고 질문을 보내면, Then 대화 내용에
  질문과 답이 차례로 나타나고 진행 상태가 "답변이 완료되었습니다."로 바뀐다.
- Given 답을 받는 중, When 화면을 새로고침하면, Then 사이드바가 열린 채로 돌아오고 받던 답이
  중복 없이 이어진다.
- Given 긴 답을 받는 중, When "중지"를 누르면, Then 입력칸이 다시 열리고 그 답 아래에 "요청을
  취소했습니다."가 남는다.

### US-DM-03 말로 한 아이디어를 AI가 전략으로 바꿔 주고 바로 백테스트한다

> 정동민으로서 빈 새 전략 화면에서 투자 아이디어를 말로 설명하고, AI가 만든 전략을 확인한 뒤 바로
> 돌려 보고 싶다. 그래야 YAML을 몰라도 내 감이 과거에 통했는지 알 수 있다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: AI 어시스턴트 · 새 전략 · 제안 적용 · 백테스트
- e2e:
  - `frontend/e2e/stories/dm.ai-new-strategy.spec.ts` :: US-DM-03 빈 새 전략에서 AI에게 아이디어를 말해 받은 전략을 적용하고 백테스트한다
  - `frontend/e2e/assistant.workflow.spec.ts` :: 제안 카드를 미리 보고 적용한 뒤 적용 후 백테스트가 실행 화면까지 간다

수용 기준

- Given 빈 새 전략 화면(백테스트가 막혀 있다), When 사이드바에서 "최근 많이 오른 대형주를 사는 새
  전략"처럼 아이디어를 말하면, Then 전략 전체를 담은 제안 카드가 "검증 통과" 배지와 함께 뜬다.
- Given 그 카드, When "문서에 적용"을 누르면, Then 문서 상태가 "검증 통과"가 되고, 저장하지 않은
  채로 "백테스트"를 눌러 결과 화면까지 간다.
- Given 저장한 전략의 사이드바, When 전략을 제안해 달라고 물으면, Then 제목·"검증 통과" 배지·출처
  링크가 있는 제안 카드가 뜬다. 출처 옆에는 링크가 실제로 가는 호스트가 보인다.
- Given 제안 카드, When "미리보기"를 누르면, Then 지금 문서와의 차이 표가 뜨고 취소하면 문서는 그대로다.
- Given 제안 카드, When "문서에 적용"을 누르면, Then "제안을 문서에 적용했습니다."가 보이고 문서
  상태가 "검증 통과"다. 제안이 바꾼 줄 말고는 문서가 그대로다.
- Given 적용해서 문서가 제안의 기준 원문과 달라진 상태, When "적용 후 백테스트"를 누르면, Then
  "문서가 바뀌었습니다" 확인을 거쳐 백테스트 실행 화면으로 가고 결과가 나온다.
- 비고: 대본 공급자의 "새 전략" 대본은 authoring schema를 따르는 본문을 가진다. schema 1.2(P2-03)가
  섹션을 바꾸면 `tests/application/test_scripted_idea_proposal.py`가 먼저 깨지고 대본을 함께 고친다.

### US-DM-04 백테스트 결과에서 핵심 숫자와 자산 곡선을 본다

> 정동민으로서 백테스트가 끝나면 긴 표보다 핵심 숫자 몇 개와 자산 곡선부터 보고 싶다. 그래야 이
> 규칙을 더 파볼지 빨리 정할 수 있다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: 백테스트 결과 · 실행 이력
- e2e:
  - `frontend/e2e/stories/dm.backtest-result.spec.ts` :: US-DM-04 저장한 전략을 백테스트하면 핵심 성과 지표 여섯 개와 자산 곡선이 보인다

수용 기준

- Given 검증을 통과해 저장한 전략, When "백테스트"를 누르면, Then 실행 화면으로 가고 실행 상태가
  완료(completed)가 된다.
- Given 완료된 결과, Then "핵심 성과 지표"에 Total return·Sharpe ratio·Maximum drawdown·Calmar
  ratio·Turnover·Closed trades 여섯 개가 값과 함께 보이고, 자산 곡선(Equity curve) 차트가 보인다.
  지표 이름의 쉬운 한글 뜻은 US-DM-08이 다룬다.
- Given 완료된 결과, When 왼쪽 메뉴의 "백테스트"를 누르면, Then 백테스트 이력에 방금 실행이
  완료 상태로 있다.

### US-DM-05 기간·유니버스·수수료·슬리피지를 전략 밖 실행 설정에서 정한다

> 정동민으로서 테스트 기간과 종목 범위, 거래 비용을 화면의 실행 설정에서 고르고 싶다. 그래야 전략
> 글을 건드리지 않고 조건만 바꿔 다시 돌려 볼 수 있다.

- 상태: `예정`
- 담당 PR: P2-01, P3-02, P3-03
- e2e 담당: P3-03
- 기능 영역: 실행 설정(`RunEnvironment`) · 백테스트
- e2e: 없음

수용 기준

- Given 저장한 전략, When 실행 설정을 열면, Then 시장·기간·유니버스·체결 시점·수수료·참여율·
  슬리피지·결측 처리가 서버가 준 기본값으로 채워져 있다.
- Given 실행 설정에서 기간만 바꾼 상태, When 백테스트를 돌리면, Then 전략 문서는 바뀌지 않고
  결과 화면의 실행 기록에 바꾼 기간이 보인다.
- Given 전략 화면 상단, Then 지금 실행 설정의 요약 띠가 보이고 "전략 문서 밖의 설정"임을 문구로
  알 수 있다.
- 비고: 현재 main에서는 기간·유니버스·수수료가 전략 YAML의 `data`·`execution` 섹션에 있다.
  schema 1.2(P2-03)가 이 섹션을 언어에서 빼고, P3-02가 실행 설정 패널을 넓힌다.

### US-DM-06 화면의 말과 오류 문장을 쉬운 한글로 읽는다

> 정동민으로서 노드·필드 이름과 오류를 한글 문장으로 읽고 싶다. 그래야 영어 식별자를 몰라도
> 무엇을 고쳐야 할지 안다.

- 상태: `예정`
- 담당 PR: P1-03, P1-04, P1-05
- e2e 담당: P1-05
- 기능 영역: 연산자 카탈로그 · i18n · compile 진단
- e2e: 없음

수용 기준

- Given 그래프 편집 화면, Then 노드 종류와 연산자, 필드가 한글 이름과 한 줄 설명으로 보이고 영어
  키는 보조 표기로만 남는다.
- Given 필드 이름을 틀린 문서, Then 문제 목록의 문장이 한글이고 무엇을 어떻게 고치면 되는지 말한다.
- Given 1.0 형식으로 적힌 문서, Then 오류와 함께 업그레이드 안내가 뜬다.
- Given 삭제가 거부된 노드, Then 거부 사유가 JSON Pointer 대신 노드 표시 이름으로 보인다(P1-04).
- 비고: lang2 WORKFLOW의 P1-05 acceptance는 메시지 golden 단위 테스트만 적고 브라우저 e2e를 적지
  않는다. 이 스토리를 `구현됨-e2e`로 올리려면 P1-05(또는 리드가 정한 PR)가 문제 목록 한글 문장을 보는
  e2e를 더해야 한다.

### US-DM-07 빈 문서에서 그래프 화면만으로 전략을 만들어 백테스트한다

> 정동민으로서 템플릿을 고르지 않고 빈 화면에서 단계 카드를 채워 전략을 만들고 싶다. 그래야 내
> 아이디어를 내 순서대로 담을 수 있다.

- 상태: `예정`
- 담당 PR: P4-04, P5-03
- e2e 담당: P4-04, P5-03
- 기능 영역: 그래프 표현(파이프라인·레시피) · 새 전략
- e2e: 없음

수용 기준

- Given 새 전략 화면, Then 기본 탭이 그래프이고 빈 문서가 "구조 오류" 없이 열린다.
- Given 그래프 화면, When 유니버스 조건·팩터·포트폴리오 구성·리스크 제약 카드를 채우면, Then
  YAML 식별자를 한 번도 보지 않고 "검증 통과"에 이른다.
- Given 완성한 전략, When 백테스트를 누르면, Then 결과 화면까지 간다.
- 비고: lang2 완료 정의의 아이디어 5개(12-1 모멘텀, 저PBR+고ROE, 20일 이평 돌파, 거래대금 상위
  20%, 변동성 역가중)가 이 스토리의 측정 기준이다. P4-04가 빈 화면 e2e를, P5-03이 아이디어 5개
  e2e를 만든다.

### US-DM-08 백테스트 결과를 AI에게 쉬운 말로 풀어 달라고 한다

> 정동민으로서 결과 화면의 숫자를 AI에게 "이게 좋은 거야?"라고 묻고 싶다. 그래야 샤프 비율이나
> 최대 낙폭을 몰라도 이 전략을 계속 볼지 판단할 수 있다.

- 상태: `미계획`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: AI 어시스턴트 · 백테스트 결과
- e2e: 없음

수용 기준

- Given 완료된 백테스트 결과 화면, When AI 어시스턴트에게 결과를 설명해 달라고 하면, Then 핵심
  지표를 쉬운 말로 풀고 벤치마크와 비교한 답이 온다.
- Given 결과 지표 이름, Then 영어 지표명 옆에 쉬운 한글 뜻이 보인다.

제품 결정 필요: 지금 어시스턴트는 전략 화면에만 붙고, 모델에게 가는 맥락은 문서 원문·compile
진단·실행 설정뿐이다(2026-09-20 AI 어시스턴트 설계). 결과 화면에 사이드바를 둘지, 실행 결과를
맥락이나 도구로 넘길지, 지표 한글 이름을 backend Metric Registry와 frontend i18n 중 어디가
소유할지를 정해야 한다. 어느 계획에도 담당 PR이 없다.
