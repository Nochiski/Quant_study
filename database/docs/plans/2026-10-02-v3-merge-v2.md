## 0. 한눈에

나누는 기준은 **모델의 전이 의존 폐포**다. 같은 stage·equity 규칙(SQL)을 쓰되, 모델이 필요로 하는 표의 폐포를 **먼저** 짓고
곧바로 모델·엑셀·호환 계층으로 넘긴다. 백테스트에만 쓰는 나머지 표는 그 뒤에(또는 덜 자주) 짓는다. 규칙은 한 벌이다.

```
수집 원장 (KRX · 키움 · WISE · DART · KIS) — 한 번만 수집
        │
        ├─▶ ① 데일리 폐포 빌드 (모델이 읽는 표와 그 의존만, 같은 규칙)
        │        └─▶ factor_inputs → 모델 → 엑셀(아침) · 호환 계층 → v3 후단(저녁·아침)
        │
        └─▶ ② 백테스트 나머지 빌드 (문서층·ETF·이벤트 원문 등 폐포 밖 표, 데일리를 막지 않음)
                 └─▶ 워크벤치 · 백테스트 · 리서치
```
