# 키움 모의투자 연결 안내

워크벤치를 **내 PC에서 내 키움 모의투자 계좌**에 연결하는 순서입니다. 윈도우와 맥이 같습니다. 키는 내 PC의
사용자 설정 폴더에만 저장되고, 서버나 다른 사람에게 가지 않습니다. 이 연결은 **모의투자 전용**이며 실전 계좌는
쓰지 않습니다.

> 키 값(App Key·App Secret)과 전체 계좌번호는 채팅·메신저·이슈·PR에 붙이지 마세요. 워크벤치 설정 화면에만
> 넣습니다.

## 1. 키움 쪽 준비

1. 키움증권 계좌를 만들고 HTS ID를 연결합니다.
2. 키움 홈페이지에서 **모의투자 → 상시모의투자 → 주식/선물옵션**으로 들어가 모의투자를 신청합니다(무료).
   - 주의: "개인 공매도 사전교육 이수용" 모의 계좌로는 주식 주문이 거부됩니다(키움 메시지 RC5006,
     2026-10-20 확인). 일반 상시모의투자 계좌를 쓰세요.
3. [키움 REST API 포털](https://openapi.kiwoom.com) 오른쪽 위 **API 사용신청**에서 로그인하고 약관에 동의합니다.
4. **모의투자 App Key 관리** 탭을 엽니다. 실전용 "계좌 App Key 관리" 탭과 다릅니다.
5. 지금 PC의 공인 IP를 등록합니다(화면의 "현재 나의 IP"). 집·회사처럼 IP가 바뀌면 다시 등록합니다.
   IP는 10개까지 등록할 수 있습니다.
6. 화면 아래 **계좌 등록하기**를 눌러 모의 계좌를 고르고, 계좌 비밀번호와 문자 인증을 거칩니다.
   처음에 계좌 목록이 비어 있는 것은 정상입니다. 이 단계를 거쳐야 생깁니다.
7. App Key와 App Secret을 내려받습니다. **다운로드는 한 번만 됩니다.** 파일을 안전한 곳에 둡니다.
   잃어버리면 포털에서 다시 발급해야 하고, 다시 발급하면 이전 키는 쓸 수 없습니다.

## 2. 워크벤치에 넣기

1. 워크벤치 왼쪽 아래 **설정**을 엽니다.
2. **키움 모의투자 연결** 섹션에 App Key, App Secret, 모의 계좌번호(숫자 10자리, `-`는 넣어도 됨)를 넣고
   **저장**을 누릅니다.
3. 입력칸이 비고 "저장됨 · 계좌 끝 NNNN"이 보이면 저장된 것입니다. 키는 다시 보여 주지 않습니다.
4. **연결 확인**을 누릅니다. 키움에 토큰을 받고 이 키에 묶인 계좌를 조회해, 입력한 계좌번호와 같은지 봅니다.
   주문은 하지 않습니다.

## 3. 연결 확인 결과별 대처

| 화면 문장 | 원인 | 할 일 |
|---|---|---|
| 연결됐습니다. | 키와 계좌가 맞습니다 | 끝 |
| 실전투자용 키로 보입니다. | 실전 탭에서 받은 키입니다(키움 8030·8031) | 1-4의 **모의투자** 탭에서 받은 키를 넣습니다 |
| 이 PC의 인터넷 주소(IP)가 키움에 등록되지 않았습니다. | 지금 IP가 등록 목록에 없습니다(8050 등) | 1-5대로 지금 IP를 등록하고 다시 확인합니다 |
| 앱 키나 시크릿이 맞지 않습니다. | 값이 틀렸거나 재발급으로 무효가 됐습니다(8001 등) | 내려받은 파일의 값을 다시 넣습니다 |
| 이 키에 묶인 계좌가 입력한 계좌번호와 다릅니다. | 계좌번호를 잘못 넣었거나 다른 계좌의 키입니다 | 포털 모의투자 탭에 보이는 계좌번호를 넣습니다. 다른 동안에는 주문이 나가지 않습니다 |
| 키움 모의 서버에서 응답을 받지 못했습니다. | 네트워크·키움 서버 문제 | 잠시 뒤 다시 확인합니다 |
| 키움이 확인 요청을 거절했습니다. | 짧은 시간에 너무 자주 눌렀거나(1초에 1번 한도) 그 밖의 거절 | 몇 초 뒤 다시 확인합니다 |

## 4. 알아 둘 것

- 키는 윈도우 `%APPDATA%\quant-workbench\secrets.json`, 맥 `~/.config/quant-workbench/secrets.json`에
  저장됩니다. 본인만 읽을 수 있게 잠깁니다. AI 어시스턴트 키와 같은 파일입니다.
- 지우려면 설정의 **삭제**를 누릅니다.
- 키움 이용안내에 따르면 **3개월 동안 실서버에 접속하지 않으면 API 서비스가 자동 해지**되고, 모의 서버만 써도
  해지될 수 있습니다. 해지되면 다시 신청해야 합니다.
- 모의투자는 KRX 종목만 되고, 같은 기능을 1초에 1번까지 부를 수 있습니다.
- 맥에서 python.org에서 받은 파이썬을 쓰면 인증서 목록이 비어 연결이 안 될 수 있습니다. 워크벤치는 설치돼
  있으면 OS 인증서 저장소(`truststore`)를 씁니다.
