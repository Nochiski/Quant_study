### 1-3. PIT 처리 (적용한 것)

| 축 | 규칙 | 근거 |
|---|---|---|
| 연간 재무 | `available_date <= 기준일` → `period_end` 최신 → CFS 우선 → `available_date` 최신. `period_end >= 기준일 − 730일` | `available_date == rcept_dt`(DART 접수일) |
| TTM 재무 | 같은 규칙으로 최신 누적 보고서를 고르고 `전기 연간 + 당기 누적 − 전기 동기 누적`. `period_end >= 기준일 − 550일` | `net_income` 등이 YTD 누적 |
| 가격·수급·공매도·신용 | `available_date = date` (전 행) — 기준일 당일 값을 그대로 | 표별 `available_basis='default'` |
| 배당 | `available_date <= 기준일`, `stlm_dt >= 기준일 − 730일` | `available_date − stlm_dt` 중앙 87일(5~95% 72~227일) |
| 컨센서스(v3) | `available_date <= 기준일`. `available_date − obs_date` 0~4일 | 아래 3-5 |
| 컨센서스(wise) | **사용 불가** | 아래 |

**결측·0 구분.** `flow_daily`·`short_daily`·`credit_daily` 의 미측정 셀은 `fill_kind` 로 이유가 붙어
있다. `short_daily` 에서 `fill_kind_short_kiwoom.kind ∈ {src_omitted, empty_response}` (증거
`shard_done`/`shard_empty`, 2020년 이후 1,757,750셀)는 **"0 으로 읽어도 되는 결측"** 이라 0 으로
채웠고, `not_collected`(517,003셀)는 NULL 로 뒀다. 나머지 표는 NULL 그대로 두고 롤링 창에서
비결측 개수 하한(20일 창 15개 / 60일 창 45개 / 120일 창 90개 / 252일 창 200개)을 걸었다.

- **월별**: 월말 거래일 72개, 2020-07-31 ~ 2026-06-30. 선행 수익률 = 다음 월말 `adj_close` 비율 − 1.

  선행 1주(다음 주말) · 4주(4주 뒤 주말).
- **U1**: `status='listed'` · `market ∈ {KOSPI, KOSDAQ}` · `sec_type='common'` · `adv20_krw >= 10억`.
  월평균 1,159종목(885~1,628), 주평균 1,078종목(883~1,354).
- **U2**: U1 중 기준일 시총 상위 800(추정치 유니버스 대용). 매 기준일 정확히 800.
- **선행 수익률 결측**: 월별 83,473행 중 17행(0.02%), 주별 252,247행 중 1주 7행 · 4주 33행.
- **방향 정렬**: 모든 후보를 "값이 클수록 기대수익이 높다"가 되도록 부호를 붙여 저장했다
  (부호를 뒤집은 것: 변동성·회전율·부채비율·발생액·1개월수익률·공매도·신용·대차). 따라서 표의
  **IC 부호가 음(−)이면 사전 가설과 방향이 반대**라는 뜻이다.
- **지표**: 기간별 Spearman Rank IC(동률 평균순위, 기간당 최소 100종목), 평균 · t = 평균/(sd/√n) ·
  양의 비율 · 반기 분할 · 십분위 D10−D1. 추가로 **시총 5분위 내 IC**(각 기준일에 시총 5분위를 나눠
  분위 안에서 IC 를 재고 종목수 가중 평균) 를 소형주 착시 점검용으로 계산했다.
- **후보 정의** (세션 수 K 는 명시적: 1개월=21 · 3개월=63 · 6개월=126 · 12개월=252 세션)

**"52주 저낙폭"을 별도 후보로 두지 않은 이유**: 52주 낙폭 = `adj_close / max(adj_close, 252) − 1`
= `M_52WH − 1` 이다. 상수 차이이므로 Rank IC 와 모든 순위상관이 `M_52WH` 와 **정확히 동일**하다.
`M_52WH` 결과가 그대로 "52주 저낙폭"의 결과다.

## 7. 한계

1. **`fin_std` 는 다판본 PIT 가 아니다.** `vintage_kind` 는 `api_restated` 단일값이고 (corp_code,
   period_end, report_code, fs_div) 당 1행뿐이다. `available_date`(=접수일)로 "언제부터 알 수
   있었나"는 지켰지만 "그때 뭐라고 적혀 있었나"는 지키지 못했다. 재작성 편향만큼 퀄리티·밸류
   후보의 IC 가 과대평가돼 있을 수 있고, 이 편향은 퀄리티 후보 **전부에 공통**으로 작용하므로
   5절의 후보 간 상관·중복 판정은 상대적으로 덜 오염됐다. 저위험·모멘텀·수급 후보는 무관하다.
2. **컨센서스 PIT 불가.** 3-6 그대로. 리비전 버킷은 판정 자체가 없다.
3. **롤링 창은 세션 위치 기반이다.** `ROWS BETWEEN n PRECEDING` 을 썼으므로 거래정지로 일별 격자에
   행이 없는 구간이 있으면 창이 달력상 더 뒤까지 뻗는다. 60일 창 15개 · 120일 창 90개 등 비결측
   하한으로 극단만 막았다.
4. **공매도 레짐.** 2020-03 ~ 2021-05 전면 금지 · 2021-05 ~ 2023-11 부분 재개 · 2023-11 ~ 2025-03
   전면 금지 구간이 표본의 대부분이다. `F_SHRT_LVL` 의 0 동률 비율이 2020년 36.0% → 2026년 0.08%
   로 바뀐다. 이 버킷의 수치는 반복되지 않을 제도 구간에서 측정된 것이다.
5. **주별 4주 수익률은 중첩 표본이다.** 234개 관측이 4주씩 겹쳐 t 가 과대평가된다. 4주마다 하나만
   쓰는 비중첩 부표본 t 를 함께 실었다(`t_nonoverlap4`, n≈59). `M_REV1M` 1주(t 3.94 → 0.48),
   `Q_GPA` 1주(5.62 → 1.18) 처럼 크게 깎이는 후보가 있다.
6. **거래비용·실행 미반영.** 기준일 종가 즉시 체결 가정. 십분위 수익률은 동일가중 단순평균이며
   섹터·시총 중립화를 하지 않았다(시총은 5분위 내 IC 로 별도 점검). 회전율이 높은 후보
   (`M_REV1M`, `F_*_CHG`)에 특히 불리하게 작동할 비용이 빠져 있다.
7. **다중검정.** 33후보 × 2유니버스 × 3지평(월1·주1·주4) = 198개 조합을 한 번에 쟀다. 사전등록이
   아니라 서술적 프로브다. 월별 66개 기준 Bonferroni 임계는 |t| ≥ 3.520 이고, 6절의 "보류" 판정은
   대부분 이 선을 못 넘었다는 뜻이다. 부호가 가설과 반대인 후보(발생액·부채비율·3·6개월 추세·
   연기금·공매도)는 **반대 방향으로 유의**하므로, 반대 부호를 새 가설로 채택하려면 별도 사전등록이
   필요하다 — 이 프로브 결과로 곧바로 뒤집어 쓰면 데이터 스누핑이다.
8. **섹터 중립 안 함.** `Q_GPA`·`Q_OPM` 처럼 업종 구조에 크게 의존하는 후보는 섹터 중립화 후
   결론이 달라질 수 있다. equity 층에 WICS 가 없어(메모: equity 데이터 실측 09-17) 이번에는 못 했다.
9. **적자·음수 처리.** `Q_ACCR` 의 31.6%가 발생액 양(순이익 > 영업현금), `V_EP < 0` 은 31.0%다.
   Rank IC 는 적자를 "가장 나쁜 쪽"으로 몰아넣는데 정의 그대로지만 실무의 "적자 제외"와는 다르다.
10. **`F_PENS20` 은 키움 축만이다.** KIS 의 `fund_ntby_tr_pbmn_krw`(기금)를 같은 주체로 확인한 축이
    없어 `pension_net_buy_kiwoom_krw` 만 썼다(`flow_daily.sql` 주석의 F04 결정). 커버리지 97.2%.
