## 4. 수정주가 규약 — 확정

```
FID_ORG_ADJ_PRC = ""  또는 "0"   →  수정주가
FID_ORG_ADJ_PRC = "1"            →  원주가 = KRX 실체결가와 완전 일치
```

**공란으로 보내지 마라.** 공란은 `"0"` 으로 해석되는데, 원장에 공란이 남으면 "의도한
수정주가인가 안 채운 건가"가 구분되지 않는다. 키움 `amt_qty_tp` 가 정확히 이 실수로 컬럼
의미를 잃었다.

**chart TR 은 `"1"`(원주가)로 수집한다.** 수정주가는 **조회 시점 의존**이라 나중에 분할이
한 번 더 나면 같은 `(종목, 날짜)` 에 다른 값이 온다 — 원장 불변성과 정면 충돌한다.
원주가는 영구 불변이고 KRX 와 완전 일치하므로 교차검증축으로 바로 쓸 수 있다.

**투자자 TR 은 이 파라미터가 무시된다**(세 값 응답 동일). 그래도 `"0"` 을 명시해 "무시되는
것을 알고 보냈다"를 원장에 남긴다. `FID_ETC_CLS_CODE` 는 **필수** — 빠지면 에러다.

폐지종목도 수정주가 로직이 살아 있다. 폐지 931건 중 액면가 변동 **92건(9.9%)**,
상장주식수 변동 **520건(55.9%)**.

### DEFECT-KIS-C: `FHPTJ04160001` 한 행 안에 단위가 두 개다

- **상황**: 액면분할 이력이 있는 종목의 분할 이전 구간
- **인풋**: `FID_INPUT_ISCD='005930'` `FID_INPUT_DATE_1='20180427'` (2018-05-04 50:1 분할)
- **에러 위치**: 응답 `output2` 의 한 행. 실측 (2018-04-25):

  | 필드 | 값 | 기준 |
  |---|---:|---|
  | `stck_clpr` | 50,400 | **수정주가** |
  | `acml_vol` | 16,614,600 | **수정 기준** |
  | 투자자 매도 4자합 | **332,292** | **원주가 기준** |
  | KRX 실체결 | 2,520,000원 / 332,292주 | — |

  정확히 **50.0배**. `acml_tr_pbmn` 은 불변(KRX `ACC_TRDVAL` 과 일치).
- **위험성**: **silent corrupt.** `acml_vol` 을 분모로 쓰는 회전율·거래비중이 분할배수만큼
  틀린다. 003410 은 **분할 이후 날짜(2018-07-17)에도 0.9128배** 오차가 남는다 — 후속
  조정 이벤트가 과거 전 구간을 소급 오염시키기 때문이다. 매수강도
  `shnu/(shnu+seln)` 는 분자·분모가 같은 계열이라 안전
- **대응**: 총거래량이 필요하면 KRX `ACC_TRDVOL` 을 조인하거나 4자합
  (`frgn+prsn+orgn+etc_corp`)을 쓴다. 투자자 TR 의 OHLCV 5컬럼은 **재수집 시 값이 바뀔 수
  있는 비결정 컬럼**이므로 그 사실을 스키마에 표기한다

### DEFECT-KIS-A: 재무 API 가 결측을 `99.99` 센티널로 채운다

- **인풋**: `FHKST66430200` `{FID_DIV_CLS_CODE:"0", fid_input_iscd:"005930"}`
- **에러 위치**: `output[]` 의 `depr_cost`·`sell_mang`·`bsop_non_ernn`·`spec_prfi` 등
- **위험성**: 삼성전자 2026-06 감가상각비가 `"99.99"` 로 온다. 단위가 억원이라 **9,999만원
  이라는 유효해 보이는 값**이다. NULL 매핑 없이 적재하면 silent corrupt

### DEFECT-KIS-B: 폐지종목의 `output1` 헤더가 전부 0

- **인풋**: `FHPST04830000` `FID_INPUT_ISCD='115390'` (2024-12-06 폐지)
- **에러 위치**: 응답 `output1`(스냅샷 헤더) — `stck_prpr:"0"`, `acml_vol:"0"`,
  `per/eps/pbr:"0.00"`, `lstg_stqt:"0"`. `output2`(일별 배열)는 정상
- **위험성**: 헤더에서 상장주식수·PER 를 뽑으면 폐지 652종목 전체가 0 으로 오염된다.
  **`output1` 은 폐지종목에서 사용 금지**

## 5. 수집 범위 — 기간이 아니라 종목을 자른다

**백테스트 시작 연도를 2010년으로 확정**했으므로 폐지 652종목 전 구간이 대상이다.
(909 − 스팩 176 − 우선주·종류주 81 = 652)

### 기간 절단이 최악인 이유 — 직관과 반대다

폐지에 가까울수록 데이터가 비어 있다:

| 창 | 거래정지 비율 | 콜당 실거래일 | 거래대금 커버 | 콜 비중 |
|---|---:|---:|---:|---:|
| **전 구간** | 13.7% | **25.6일** | 100% | 100% |
| 24개월 | 31.7% | 19.7일 | 21.6% | 29.8% |
| 12개월 | 39.2% | 16.7일 | 10.3% | 17.5% |
| 3개월 | **55.3%** | **9.6일** | 2.0% | 6.2% |
| 1개월 | 64.4% | — | — | — |

**"3개월만 받으면 콜 94% 절감"은 사실이지만 그 3개월은 절반 이상이 빈 페이지다.**
어느 창에서도 경제적 커버리지가 콜 비중을 넘지 못한다. 게다가 팩터 룩백(F01 은 N일 누적,
F02 는 t−N 차분)이 창 시작 구간을 NaN 으로 만든다.

### 예산

| 대상 | 팩터 | 콜 |
|---|---|---:|
| 수급 `FHPTJ04160001` (30행/콜) | F01·F03·F04 | 31,649 |
| 공매도 `FHPST04830000` (100행/콜) | F05·F06 | 9,716 |
| 대차 `HHPST074500C0` (100행/콜) | F07 | 9,716 |
| **계** | **6개** | **51,081** |

유량 실측: `sleep(0.1)` 에서 **초당 5콜**. 네트워크 왕복이 병목이라 유량 제한(초당 20건)에
닿지 않는다. **약 3시간.** DART 채널과 완전히 별개라 동시 실행 가능.

## 6. 착수 전 미결

### M1. 공매도·대차 "해당 없음"을 사전에 가릴 방법이 없다

0행에는 **다섯 가지 원인**이 섞인다:

| 원인 | 성격 |
|---|---|
| 제도적으로 대상이 아님 (스팩 등) | 해당 없음 |
| 그날 거래정지 | 해당 없음 |
| 공매도 금지 레짐 | 해당 없음 |
| 실제로 0건 | **값이 0** |
| 수집 실패 | **결측** |

앞의 셋을 0 으로 넣으면 그 종목이 "공매도 없는 안전한 종목"으로 랭킹 상위에 몰린다.
폐지종목은 거래정지가 많아(3개월 전 55.3%) 오염이 크다.

**사전 판별 수단이 없다**(실측):
- KRX 원장 `krx_stk_bydd_trd`·`krx_stk_isu_base_info` 에 공매도·대차 가능 여부 필드 없음
- KRX OpenAPI 31종에 공매도·대차 카테고리 자체가 없음 (`srtsl`·`loan_bal` 404)
- `krx_kospi_dd_trd` 는 **지수 시세만** 주고 구성종목을 주지 않음

**대응**: 쏘되 **0행의 원인 판정 근거를 원장에 함께 남긴다.** 거래정지 여부는 KRX 원장
`ACC_TRDVOL` 로 콜 없이 알 수 있고, 공매도 금지 레짐도 알려진 날짜다. 이렇게 하면
키움 원장의 결함(`ingest_shard.status` 가 `{done, empty}` 2값뿐이라 원인을 담을 자리가
없음)을 반복하지 않는다.

### M2. 대차 TR 미검증

`HHPST074500C0` 은 2024년 구간은 나오는데 2010-01~04 는 0행이다. 소급 하한 미측정.
**1콜 프로브로 확정한 뒤 착수**한다 — 프로브 없이 9,716콜을 태우면 키움 `ka20068` A구간과
같은 0-패딩(성공응답 + 만행수 + 전량 0)을 원장에 넣을 위험이 있다.

폐지 652 중 **146종목(22.4%)은 마지막 거래일이 2011-07-25 이전**이라 대차 데이터가 원천
부재다. 실대상은 506종목.

## 7. 콜 0 으로 얻는 것

### KOSDAQ 부실 라벨이 이미 원장에 있다

`krx_ksq_bydd_trd.SECT_TP_NM` — 폐지종목 KOSDAQ 행 실측:

관리종목(소속부없음)        68,076행

날짜축 수집의 부산물이라 **PIT 가 깨끗하다.** DART FY2015 하한 아래로 내려가므로
**E07(상폐 위험)의 KOSDAQ 사이드를 DART 없이 즉시 만들 수 있다.**

한계: KOSPI 는 `SECT_TP_NM` 이 전량 공백이다(폐지종목 447,100행 = 47.6%).

### F05·F06·F07 의 분모는 이미 있다

`LIST_SHRS`(상장주식수)·`ACC_TRDVAL`(거래대금)이 939,610행 전부 채워져 있다.
부족한 것은 **분자 하나씩**이고 분모 확보 콜은 0 이다.

## 8. 원장 감사 — KRX·키움

두 DB 모두 **원장 계약(무손실 보존) 기준으로는 대체로 적절**하다. BCNF 위반은 있으나

### 키움 원장이 실제로 깨진 곳 3건

**`ovr_shrts_qty` 톱니파** — 누적공매도량이 API 응답창(372행)마다 리셋되는데 그걸 이어붙였다.
실측 낙차 지점의 역순번이 **372·744·1116·1488·1860·2232·2604·2976** 로 정확히 372 배수이고,
각 리셋 행에서 `ovr_shrts_qty == shrts_qty` 다. 005930 은 2020-07-01 에 1억7,050만주 →
2,020주. **seam 위치가 `ingest_shard.next_cursor`(100% NULL)에 없어 원장만으로 복원 불가** —
`행수 mod 372` 로 역산해야 한다.

**`amt_qty_tp` 미보존** — 컬럼 전체의 의미를 바꾸는 요청 파라미터가 어디에도 없다.

**`ingest_shard.last_dt` 가 관측값이 아니라 요청값 복사본** — done shard 2,605/2,605 에서
`last_dt = req_end`. 데이터 0행인 60종목이 "최신"으로 통과한다.
