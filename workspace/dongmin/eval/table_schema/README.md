# 표 스키마 추론 골든셋 (table_schema) — 2026-09-03

DART 정기보고서의 **자유 서식 표**(XBRL·EXTRACTION 서식이 아닌 편집기 표) 하나를 주면
"열의 역할 · 단위 · 표 주제 · 합계 행"을 맞히는지 재는 평가셋. 숫자는 코드가 원문 셀에서 복사하므로
이 네 가지의 정확도가 추출 정확도의 상한이다. 설계 배경은 `docs/DOC_DESIGN.md` §1.9·§1.12, 원칙은
kael-system-v3 `docs/local_llm_playbook.md`(숫자 재타이핑 금지·코드로 채점).

## 라벨링 방법
1. `cases.md`에서 `T001`부터 표를 보며 두 CSV를 채운다. **빈칸으로 두면 `_draft` 값을 정답으로 인정**한다. 초안이 틀리면 `unit`·`topic`·`total_rows`·`role` 칸에 정답을 적는다. 초안이 비어 있으면 반드시 채운다.
2. `labels_columns.csv`의 `rule_confident=N` 열(249개)은 규칙이 확신 못 한 열이니 꼭 본다. `Y`(267개)는 `제N기`·`당기`·`전기` 같은 명시 헤더에서 나온 것이라 빠르게 훑는다.
3. 어휘
   - `role`: `label`(항목 이름 열) · `current`(당기·당분기·당반기·당기말·제N기 중 최신) · `prior`(전기·전분기·전반기·전기말) · `prior2`(전전기) · `change`(증감·변동·차이) · `ratio`(비율·비중·구성비) · `other`(그 밖의 값 열: 비고·소재지·결산월·수량 등) · `none`(완전히 빈 열)
   - `unit`: `원` · `천원` · `백만원` · `억원` · `주` · `%` · `명` · `기타`(예: 원/kg, 톤) · `불명`(표·제목 어디에도 단위가 없음)
   - `total_rows`: 합계·계·총계·소계 행의 행 번호(`cases.md`의 `r7` 이면 `7`)를 쉼표로. 없으면 `-`를 적는다(빈칸은 초안 인정이므로).
   - `topic`: 표가 무엇의 표인지 한 구절. 초안은 표 앞 제목에서 번호를 뗀 것. 제목이 없거나 엉뚱하면 첫 열 헤더 등에서 적절히.
4. 판단이 애매하면 `note`에 한 줄. 두 전문가가 다르게 볼 수 있는 표는 나중에 평가에서 제외하거나 별도 태그로 뺀다.

## 채점 (예정)
프로그램 채점. 열 역할 정확도(열 단위) · 단위 정확도 · 주제 일치(정규화 후 부분 일치) · 합계행 F1 을 따로 두고,
헤드라인은 **표 하나의 네 항목이 전부 맞은 비율**. 비교 대상: 규칙만 · 로컬 gemma4 · Claude(이 세션). 각 2회 반복, 잡음 폭 약 ±7점.
