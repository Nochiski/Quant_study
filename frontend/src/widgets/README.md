# widgets

페이지에서 독립적 의미를 갖는 큰 UI 블록. 여러 feature/entity를 조합하되 비즈니스 상태의 정본은
소유하지 않는다.

| slice | 소유한 블록 |
| --- | --- |
| `app-shell` | 앱 틀: 브랜드, 연구·운영(향후) 메뉴, 접기, 라우트 화면 자리 |
| `strategy-ide` | 전략 문서 IDE 틀: 위쪽 막대, 개요·스니펫, 편집기와 표현 탭, Contract Inspector, 중간 결과(디버거) 패널의 배치·크기 조절 |
| `market-overview` | 홈 시장 블록: 지수 카드·투자자별 순매수 카드·섹터맵 카드(지도/표, 카드 안 드릴다운, 좁으면 목록), 접기. 드릴다운 자리는 페이지가 주소로 넘긴다 |
