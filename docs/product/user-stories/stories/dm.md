# 정동민 유저 스토리

퀀트는 잘 모르는 국내 주식 개인 투자자다([페르소나](../personas.md#정동민-dm)). 쉬운 말과 AI
도움으로 자기 투자 감을 규칙으로 바꾸고 결과를 이해하는 것이 이 사람의 여정이다.

### US-DM-01 AI 공급자를 한 번 연결해 둔다

> 정동민으로서 설정 화면에서 AI 공급자를 한 번만 연결해 두고 싶다. 그래야 전략 화면에서 모르는
> 것을 바로 물어볼 수 있다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: 설정 · AI 공급자
- e2e:
  - `frontend/e2e/assistant.workflow.spec.ts` :: 설정에서 공급자를 등록하면 활성이 되고 키는 꼬리 4자리만 남는다

수용 기준

- Given 등록된 공급자가 없는 설정 화면, When 표시 이름과 API 키를 넣고 "연결 테스트 후 저장"을
  누르면, Then 그 이름의 카드가 생기고 "활성" 배지가 붙는다.
- Given 방금 저장한 공급자, Then 카드에는 키의 끝 네 자리만 보이고 키 입력칸은 비어 있으며 화면
  어디에도 키 원문이 없다.
- Given 저장된 공급자 카드, When "연결 테스트"를 누르면, Then "연결 확인됨"이 보인다.

### US-DM-02 모르는 말을 전략 화면에서 바로 묻는다

> 정동민으로서 전략 화면을 떠나지 않고 "모멘텀 전략이 뭐야?" 같은 질문을 하고 싶다. 그래야 따로
> 검색하느라 흐름이 끊기지 않는다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: AI 어시스턴트 · 사이드바 대화
- e2e:
  - `frontend/e2e/assistant.workflow.spec.ts` :: 사이드바 질문에 답이 스트리밍되고 새로고침해도 이력과 진행 중 턴이 이어진다

수용 기준

- Given 공급자가 연결된 전략 화면, When "AI 어시스턴트"를 펼치고 질문을 보내면, Then 대화 내용에
  질문과 답이 차례로 나타나고 진행 상태가 "답변이 완료되었습니다."로 바뀐다.
- Given 답을 받는 중, When 화면을 새로고침하면, Then 사이드바가 열린 채로 돌아오고 받던 답이
  중복 없이 이어진다.
- Given 긴 답을 받는 중, When "중지"를 누르면, Then 입력칸이 다시 열리고 그 답 아래에 "요청을
  취소했습니다."가 남는다.

### US-DM-03 말로 한 아이디어를 AI가 전략으로 바꿔 주고 바로 백테스트한다

> 정동민으로서 빈 새 전략 화면에서 투자 아이디어를 말로 설명하고, AI가 만든 전략을 확인한 뒤 바로
> 돌려 보고 싶다. 그래야 YAML을 몰라도 내 감이 과거에 통했는지 알 수 있다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: AI 어시스턴트 · 새 전략 · 제안 적용 · 백테스트
- e2e:
  - `frontend/e2e/stories/dm.ai-new-strategy.spec.ts` :: US-DM-03 빈 새 전략에서 AI에게 아이디어를 말해 받은 전략을 적용하고 백테스트한다
  - `frontend/e2e/stories/dm.ai-new-strategy.spec.ts` :: US-DM-03 사이드바와 계약 서랍을 어느 입구로 펼쳐도 머리 줄이 펼친 자리에서 눌린다
  - `frontend/e2e/stories/dm.sidebar-scrollbar.spec.ts` :: US-DM-03 스크롤바가 폭을 차지하는 창에서도 사이드바가 붙었다 떴다 하지 않는다
  - `frontend/e2e/assistant.workflow.spec.ts` :: 제안 카드를 미리 보고 적용하고 실행 취소·다시 실행한 뒤 적용 후 백테스트가 실행 화면까지 간다

수용 기준

- Given 빈 새 전략 화면(백테스트가 막혀 있다), When 사이드바에서 "최근 많이 오른 대형주를 사는 새
  전략"처럼 아이디어를 말하면, Then 전략 전체를 담은 제안 카드가 "검증 통과" 배지와 함께 뜬다.
- Given 그 카드와 비어 있는 실행 설정, When "적용 후 백테스트"를 누르면, Then 문서 상태가 "검증 통과"가
  되지만 백테스트는 시작하지 않고, 알림이 "백테스트를 시작하지 않았습니다" 뒤에 "실행 설정에서
  시작일·종료일·유니버스 칸을 채우세요."를 붙인다. 실행 설정은 전략 문서 밖이라 AI 적용이 채우지 않는다.
- 실행 설정 채우기: Given 그 상태, When 요약 띠의 "실행 설정 채우기"를 누르면, Then 실행 설정 패널이 열리고
  시작일 칸에 초점이 간다. 기간·유니버스를 정하면 "백테스트"가 열리고, 저장하지 않은 채로 누르면
  "저장하지 않은 변경이 있습니다" 확인이 뜬다. "나가기"를 누르면 결과 화면까지 간다.
- Given 사이드바를 연 1440px 편집 화면, Then 편집기 툴바의 실행 설정·검증·리비전 저장·백테스트, 보기 탭
  (Graph·Diff), 문서 상태, "중간 결과 접기"가 옆 칸이나 겹쳐 뜬 패널에 깔리지 않아 마우스로 누를 수 있다.
  편집기 칸이 최소 폭(480px)을 지키지 못하면 나중에 연 패널이 먼저 연 오른쪽 패널(계약) 자리에 겹쳐
  뜬다(#269, #290 리뷰 P2-1). 전략 구조를 접어 사이드바를 계약 옆에 붙인 1440px과 1280px 기본 화면에서도
  같다 — 칸이 좁으면 툴바와 탭 줄이 다음 줄로 내려간다(#296).
- Given 겹쳐 뜨는 서랍(1440·1280px 사이드바, 1440px에서 사이드바를 붙인 뒤 연 계약, 1200px 좁은 화면의
  사이드바·계약), When 서랍을 펼치면(사이드바는 상단 바 토글·Alt+A·명령 팔레트 어느 쪽으로든), Then 페이지가
  굴러가지 않고 서랍은 상단 바·실행 설정 띠 아래 본문 높이에 떠서, 머리 줄의 제목과 닫기("사이드바 닫기"·
  "계약 접기")가 펼친 자리 그대로 상단 바에 깔리지 않고 눌린다(#325, #290 리뷰 r3 P2-1).
- Given 페이지 세로 스크롤바가 폭을 차지하는 창(Windows 기본)에서 사이드바를 붙이면 페이지가 길어져
  스크롤바가 생기는 크기, Then 사이드바는 한 자리에 머물고 붙었다 떴다를 되풀이하지 않는다(#290 리뷰
  P1-1).
- Given 저장한 전략의 사이드바, When 전략을 제안해 달라고 물으면, Then 제목·"검증 통과" 배지·출처
  링크가 있는 제안 카드가 뜬다. 출처 옆에는 링크가 실제로 가는 호스트가 보인다.
- Given 제안 카드, When "미리보기"를 누르면, Then 지금 문서와의 차이 표가 뜨고 취소하면 문서는 그대로다.
- Given 제안 카드, When "문서에 적용"을 누르면, Then "제안을 문서에 적용했습니다."가 보이고 문서
  상태가 "검증 통과"다. 제안이 바꾼 줄 말고는 문서가 그대로다.
- Given 적용해서 문서가 제안의 기준 원문과 달라진 상태, When "적용 후 백테스트"를 누르면, Then
  "문서가 바뀌었습니다" 확인을 거쳐 백테스트 실행 화면으로 가고 결과가 나온다.
- 비고: 대본 공급자의 "새 전략" 대본은 authoring schema를 따르는 본문을 가진다. schema 1.2(P2-03)부터
  본문에 기간·유니버스(`data`)와 수수료(`execution`) 섹션이 없고, 모멘텀은 수정주가 `price.adj_close`로
  잰다. `tests/application/test_scripted_idea_proposal.py`가 본문이 현재 schema로 compile되는지 고정한다.
- 비고: 백테스트·추적 전에 실행 설정 패널에서 기간과 유니버스를 정한다(US-DM-05).

### US-DM-04 백테스트 결과에서 핵심 숫자와 자산 곡선을 본다

> 정동민으로서 백테스트가 끝나면 긴 표보다 핵심 숫자 몇 개와 자산 곡선부터 보고 싶다. 그래야 이
> 규칙을 더 파볼지 빨리 정할 수 있다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: 백테스트 결과 · 실행 이력
- e2e:
  - `frontend/e2e/stories/dm.backtest-result.spec.ts` :: US-DM-04 저장한 전략을 백테스트하면 핵심 성과 지표 일곱 개와 자산 곡선이 보인다

수용 기준

- 실행 설정 채우기: Given 검증을 통과해 저장한 전략과 비어 있는 실행 설정, Then "백테스트"가 막혀 있고 요약
  띠가 "실행 설정에서 시작일·종료일·유니버스 칸을 채우세요."라고 말한다. When 띠의 "실행 설정 채우기"를 누르면, Then
  패널이 열리고 시작일 칸에 초점이 간다. 기간·유니버스를 정하면 "백테스트"가 열린다.
- 같은 상태(실행 설정만 빈 저장한 전략)에서 편집기 아래 "중간 결과"도 막힌 이유를 "추적은 실행 설정 위에서
  돕니다."라는 한 문장으로만 말한다. "현재 실행 가능한 문서가 없습니다." 같은 문서 탓 문장은 함께 뜨지 않는다
  (이슈 #260).
- Given 기간·유니버스를 채운 뒤 초기 자본을 0으로 바꾼 상태, Then "백테스트"가 막히고 요약 띠가 "실행 설정의
  초기 자본 칸을 고치세요: 0보다 큰 숫자를 입력하세요."라고 말한다. When 띠의 "실행 설정 고치기"를 누르면,
  Then 패널이 열리고 초기 자본 칸에 초점이 간다. 값을 고치면 "백테스트"가 다시 열린다(이슈 #260).
- Given 검증을 통과해 저장하고 실행 설정을 채운 전략, When "백테스트"를 누르면, Then 실행 화면으로 가고
  실행 상태가 완료(completed)가 된다. 서버가 시작을 거절하면 툴바가 "백테스트 시작 실패: " 뒤에 거절 코드의
  한글 문장을 보이고, 서버 원문은 접힌 "서버 사유"에 둔다. 거절이 칸을 짚으면 "서버가 실행 설정의 초기 자본 칸
  값을 받지 않았습니다."처럼 그 칸 이름을 말한다(새 전략·저장한 전략 화면 모두). 영문 진단(`API request
  failed …`)은 보이지 않는다.
- Given 첫 세션부터 마지막 세션까지 1년 이상인 완료된 결과, Then "핵심 성과 지표"에 Total
  return·Sharpe ratio·Sharpe standard error·Maximum drawdown·Calmar ratio·Turnover·Closed trades
  일곱 개가 값과 함께 보이고, 자산 곡선(Equity curve) 차트가 보인다. 샤프 바로 옆의 표준오차는 샤프
  점추정이 운만으로 얼마나 흔들릴 수 있는지 보여 준다(이슈 #274). 1년 미만 실행은 Calmar ratio가 "N/A"와 "기간이
  1년보다 짧아 연율로 바꾸지 않습니다"를 보인다. 실행이 롤링 창보다 짧아 롤링 샤프 값이 하나도 없으면
  차트는 "실행이 롤링 창(126세션)보다 짧아 롤링 샤프 값이 없습니다."처럼 결과가 알려 준 창 길이로 이유를
  말한다(이슈 #303). 창보다 긴 실행인데 값이 비면(거래가 없어 흔들림이 0인 경우 등) 일반 빈 문구를
  보인다. 브라우저 e2e 실행은 1년 이상이라 이 경로는 frontend
  `backtest-run-detail.test.tsx`가 확인한다. 지표 이름 옆의 쉬운 한글 뜻은 US-DM-08이 지킨다.
- Given OOS 시작일을 종료일 1년 안쪽으로 둔 실행, Then 결과의 지표 표에서 OOS 구간의 cagr·calmar
  칸은 값 대신 "N/A"와 "기간이 1년보다 짧아 연율로 바꾸지 않습니다"를 보이고, 총수익률은 값으로 보인다.
  1년 미만을 연율로 부풀리면 짧은 구간의 우연한 상승이 과대평가된다(이슈 #274). 세션 종료 자산이 0
  이하가 된 실행은 CAGR 0%(본전) 같은 결과를 내지 않고 자본 잠식으로 멈춰 실패로 끝난다. 실패 안내는
  서버 내부 오류가 아니라 "세션 종료 자산이 0 이하가 되어 실행이 멈췄습니다(자본 잠식)."로 시작해 전략이
  자본을 모두 잃은 결과라고 말한다(이슈 #285). 브라우저 e2e는 1년 미만 경로만 밟는다. 자산 0 멈춤은
  backend `tests/test_rust_driver.py`가 두 코어에서, 실패 코드는 `tests/integration/test_backtest_http_api.py`가
  확인한다.
- Given 완료된 결과, When 왼쪽 메뉴의 "백테스트"를 누르면, Then 백테스트 이력에 방금 실행이
  완료 상태로 있다.
- 비고: 섹터 정보가 없는 실데이터(duckdb 원장)에서는 섹터 상한이 적용되지 않는다. 대신 섹터 상한이
  걸릴 수 있는 설정(기본 상한 0.3 등)이면 결과의 "Manifest · 데이터 경고 · 재현성 정보"에 섹터
  제약에서 뺀 종목 수와 프레임을 적은 경고가 뜬다(이슈 #203). 상한이 전체 노출 이상이고 섹터 중립이
  꺼져 있으면 결과가 같으므로 경고하지 않는다. 전에는 이 경고 없이 포트폴리오가 섹터 상한만큼(기본
  30%)으로 줄어 핵심 숫자가 틀렸다. mock 데이터는 종목마다 섹터가 있어 브라우저 e2e는 이 경로를
  밟지 않는다. 경고와 비중은 backend 통합 테스트
  (`test_unknown_sectors_keep_the_full_book_and_warn_in_preview_trace_and_run`)가 확인한다.
- 비고: 실데이터에서 원장이 계수를 내지 못한 층 이동(감자 등 `krx_base_inconsistent`)이 있는 종목을
  들고 있으면, 적용일 KRX 기준가 비로 보유 수량을 조정하고 "Manifest · 데이터 경고 · 재현성 정보"에
  사건마다 `equity.unfolded_level_shift` 경고가 뜬다(이슈 #369). 전에는 사건 없이 원주가만 나가 그 종목
  손익이 층 배수만큼(실원장 최대 ×46.8) 튀었다. 원장 카탈로그가 그 사건을 읽을 뷰를 아직 싣지 않았으면

수용 기준

- Given 저장한 전략, When 실행 설정을 열면, Then 시장·빈도·체결 시점·수수료·참여율·슬리피지·결측

  처음 쓸 때 비어 있고, 정하기 전에는 백테스트가 막힌다.
- Given 실행 설정에서 기간만 바꾼 상태, When 백테스트를 돌리면, Then 전략 문서는 바뀌지 않고
  결과 화면의 실행 기록에 바꾼 기간이 보인다(같은 strategy hash, 다른 실행 설정 hash).
- Given 전략 화면 상단, Then 지금 실행 설정의 요약 띠가 보이고 "전략 문서 밖의 설정"임을 문구로
  알 수 있다.
- Given 기간·유니버스를 정한 뒤 수수료를 -1로 바꾼 상태, Then 백테스트가 막히고 요약 띠가 "실행
  설정의 수수료 칸을 고치세요: 0bp 이상이어야 합니다."라고 말한다. When 띠의 "실행 설정 고치기"를
  누르면, Then 패널이 열리고 수수료 칸에 초점이 간다. 여러 칸이 틀리면 패널 순서의 첫 칸을 말하고
  나머지 개수를 붙인다.
- Given 실행 설정 패널, Then 매도 거래세율 칸은 매도 거래세가 "직접 입력"일 때만, 가격 충격 계수 칸은
  가격 충격 모델이 "√ 가격 충격"일 때만, 슬리피지 칸은 "고정 bp(슬리피지)"일 때만 켜진다. When 매도
  거래세를 "직접 입력"으로 바꾸고 세율 칸을 비워 두면, Then 백테스트가 막히고 요약 띠가 "실행 설정에서
  매도 거래세율 칸을 채우세요."라고 말한다. When 방식을 되돌리면, Then 세율 칸이 꺼지고 그 칸에 남은 값은
  실행에 쓰이지 않아 백테스트를 막지 않는다(#352).
- Given 비어 있는 시작일 칸, When 키보드로 `20210101`을 이어 치거나 `2021-01-01`을 치면, Then 칸에
  `2021-01-01`이 들어간다(연도 4자리 뒤에 월로 넘어간다). When 연도만 치고 칸을 떠나면, Then 칸은 비어
  있고 칸 아래에 "값을 정하세요." 대신 "연·월·일을 모두 올바르게 입력하세요. 예: 2021-01-01"이 뜬다
  (이슈 #264). 요약 띠도 "채우세요"가 아니라 "실행 설정의 종료일 칸을 고치세요: 연·월·일을 모두 올바르게
  입력하세요. …"로 같은 원인을 말한다(#266 리뷰 P3-1). 날짜 칸은 1900-01-01부터 9999-12-31까지 받는다. 선택 칸인 OOS 시작일은 비우면 OOS 없이
  실행하지만, 연도만 치고 떠나면 칸이 `aria-invalid`가 되고 요약 띠가 "실행 설정의 OOS 시작일 칸을
  고치세요: 연·월·일까지 모두 올바르게 입력하세요. 비워 두면 OOS 없이 실행합니다."라고 말하며
  "백테스트"가 막힌다(#266 리뷰 P2-1). 칸을 떠나지 않고 `Ctrl+Shift+Enter`를 눌러도 시작 요청이 나가지 않고,
  띠의 "실행 설정 고치기"는 OOS 칸으로 초점을 옮긴다(#266 재리뷰 P3-1·P3-2). OOS 칸에서는 빈 칸에 치거나
  다 친 날짜를 한 자리 지워 고쳐 치는 도중에 칸 아래·요약 띠·오류 목록에 오류가 서지 않고 "백테스트"만
  막힌다. 오류는 칸을 떠날 때 보인다(#270, #297 리뷰 P3-1·재리뷰 P2-1).
- Given 실행 설정 패널, Then 참여율은 스키마의 표시 단위(%)로 보이고(기본 10), 요청에는 비율(0.1)로
  실린다. 결과 화면 실행 기록의 "실행 설정"도 스키마의 칸 이름·단위·값 이름(예: 결측 처리 "그 종목을
  빼기", 참여율 "10%")으로 보인다.
- 비고: schema 1.2(P2-03)에서 기간·유니버스·수수료·체결은 전략 YAML의 `data`·`execution`
  섹션에서 빠져 실행 요청의 `environment` 로 옮겨졌다. P3-02가 실행 설정 패널(필드·기본값·범위는
  `/run-environments/schema`)과 요약 띠를 만들었다. 실행 설정은 전략 문서 밖에 있어 바꿔도 전략
  버전이 늘지 않는다. 마지막 사용값은 브라우저에 남아, 그 전략에서 쓴 값이 있으면 그 값으로, 없으면
  이 브라우저에서 마지막으로 쓴 값으로 다시 채워진다. IDE 위 요약 띠가 지금 값을 보인다.

  e2e 는 빈 문서에서 같은 `spec_hash` 에 도달해야 한다. 모멘텀·이평·변동성은 수정주가
  `price.adj_close`로 재야 한다(이슈 #214). 원주가 `price.close`는 분할·병합 날 끊겨 선정이 틀어진다.
- 비고(P4-02, 2026-09-30): 그래프 탭 맨 위에 단계 카드 캔버스가 들어왔다. 요약 띠, 1~4단계 카드(문장 안
  컨트롤, 규칙 추가·삭제), "5 실행" 안내가 있다. 카드 컨트롤은 Form 행과 같은 연산을 낸다(route 테스트).

### US-DM-08 백테스트 결과를 AI에게 쉬운 말로 풀어 달라고 한다

> 정동민으로서 결과 화면의 숫자를 AI에게 "이게 좋은 거야?"라고 묻고 싶다. 그래야 샤프 비율이나
> 최대 낙폭을 몰라도 이 전략을 계속 볼지 판단할 수 있다.

- 상태: `구현됨-e2e`
- 담당 PR: 없음
- e2e 담당: 없음
- 기능 영역: AI 어시스턴트 · 백테스트 결과 · 지표 쉬운 뜻
- e2e:
  - `frontend/e2e/stories/dm.result-explain.spec.ts` :: US-DM-08 완료된 백테스트 결과에서 AI에게 좋은 결과인지 물으면 지표 뜻과 벤치마크 비교를 쉬운 말로 답한다

수용 기준

- Given 완료된 백테스트 결과 화면, Then "핵심 성과 지표" 일곱 개마다 영어 지표 이름 옆에 쉬운
  한글 이름과 한 줄 뜻이 보인다(예: Sharpe ratio 옆에 "샤프 비율 흔들림 한 단위당 한국은행
  기준금리보다 얼마나 더 벌었는지입니다."). 샤프·소르티노는 한국은행 기준금리를 넘는 수익으로 재므로
  뜻 문장이 그 기준을 말한다. 예금처럼 기준금리만큼 버는 곡선은 샤프가 0 근처다(이슈 #274).
  Sharpe standard error 옆에는 "샤프 비율 오차"와, 샤프 ± 이 값의 2배가 대략 95% 범위이며 날마다
  독립이라고 본 근사라 실제로는 더 클 수 있다는 뜻 문장이 보인다.
- 실행 설정 채우기: Given 저장한 전략과 비어 있는 실행 설정, When 요약 띠의 "실행 설정 채우기"를 눌러
  기간·유니버스를 정하고 벤치마크 종목을 넣으면, Then "백테스트"가 열려 결과 화면까지 간다.
- Given 벤치마크를 정해 돌린 완료된 결과 화면, When "AI에게 결과 묻기"를 눌러 열린 "AI 어시스턴트"
  패널에서 "이 결과 좋은 거야?"라고 물으면, Then 진행 상태가 "답변이 완료되었습니다."가 되고, 답에
  화면과 같은 총수익률 값, 같은 기간 벤치마크와의 비교, 샤프 비율·최대 낙폭의 쉬운 뜻, 과거 결과가
  앞으로를 보장하지 않는다는 말이 담긴다.
- Given 결과 화면의 AI 패널, Then 전략 문서를 바꾸는 제안 카드나 "문서에 적용" 버튼이 나오지 않는다.
  결과 화면의 대화는 설명 전용이다.
- Given 아직 끝나지 않은 실행 화면, Then "AI에게 결과 묻기" 버튼이 없다.
- 비고: 설계는 `docs/superpowers/specs/2026-09-27-ai-backtest-result-explain.md`(AI PLAN D-01~D-03)가
  정본이다. 결과 대화는 실행 하나에 붙는 별도 세션이고, 모델은 서버가 그 실행에서 읽은 요약만
  받는다. 지표의 쉬운 이름·뜻은 frontend i18n이 소유한다.
- 비고: e2e는 대본 공급자 위에서 돈다. 대본은 서버 요약에서 숫자를 읽어 답하므로 요약이 모델까지
  가는 경로와 설명 전용 모드는 지키지만, 실제 모델 설명의 품질은 검사하지 않는다. 벤치마크 없이
  돌린 결과에서 "비교할 기준이 없다"고 답하는 갈래는 backend 대본 테스트가 본다.
- 비고: 백테스트·추적 전에 실행 설정 패널에서 기간과 유니버스를 정한다(US-DM-05).
