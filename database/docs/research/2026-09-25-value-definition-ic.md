- `vintage_kind`: **`api_restated` 단일값**. (corp_code, period_end, report_code, fs_div) 조합당

### 1-4. `consensus_daily` 의 PIT 문제 (중요)

- 선행 EPS 축: `metric='eps'`, `src='wise'`, `unit='원'`, 106,763행, `obs_date` 2023-09-27 ~ 2026-09-18.
- **하지만 월별 종목 수가 2025-07 까지 167개 이하**다. 2025-08-29 관측부터 2,544종목으로 점프하고
  그 뒤로 2,55x~2,61x 종목이 유지된다. 즉 **실질 이력은 2025-08 부터 13개 관측**.
- **`available_date` 는 전부 2026-09-01 이후다.** wise 축 213,398행의 `available_date` 분포는
  2026-09-01(111,007행) · 2026-09-11(93,022행) 등 최근 날짜뿐이다 — 전 구간이 2026-09 에 한꺼번에
  백필됐다. 따라서 **엄격 PIT(`available_date <= 기준일`) 로는 과거 어느 월말에도 쓸 수 있는 행이 0건**이다
  (`build_panel.py` 가 출력: `컨센서스 엄격 PIT … 사용 가능 행: 0`).
- 그래서 C 는 **완화 PIT**(`obs_date <= 기준일`, 70일 이내 신선도)로만 계산했고 **참고용**으로만 본다.
  WISE 월말 스냅샷이 그 시점 컨센서스를 그대로 보존한 것인지(재작성 없음) 이 판으로는 검증 불가.
- `target_period` 는 12월 결산 기준으로 `202612`(98,108) · `202712`(68,219) · `202812`(68,237) 에 몰려 있고
  `202512` 는 239행뿐이다. 즉 2025년 관측 시점에 **당해(2025) 추정치는 사실상 없고** 차년 이후만 있다.

### 1-5. PIT 처리 규칙 (적용한 것)

- 재무: `available_date <= 기준일` 인 행 중 `period_end` 최신 → 동률이면 **CFS 우선** → `available_date` 최신.
  추가로 `period_end >= 기준일 − 730일`(연간) / `− 550일`(TTM용 누적)로 과도한 stale 제거.
- 가격: `price_daily.available_date − date = 0` (전 행). 기준일 종가·시총을 그대로 사용.
- 컨센서스: `obs_date <= 기준일` 이고 70일 이내, (ticker, target_period) 별 최신 `obs_date`.

## 4. 결론 3줄

1. **가장 나은 것은 A 계열의 E/P — 연간이든 TTM이든 사실상 동률**이다.
   U1 72개월 IC 0.0994(t 8.71, 양의 87.5%) / TTM 0.0998(t 8.68, 88.9%), U2 에서도 0.089 / 0.087.
   TTM 은 분기 재무를 추가로 요구해 커버리지가 6% 낮은데(72,154 vs 77,075행) IC 이득은 0.0004 라
   **연간만으로 충분하다**. B/M 은 E/P 보다 한 단계 약하고(IC 0.076~0.085, t 5.0~5.1) 2023~2025 에
   IC 0.035~0.05 까지 눌렸다가 2026 에 되살아나 레짐 의존이 크다.
2. **B(v3 기말가 고정)의 손실은 E/P 에서 IC −7~11%, B/M 에서 −26~28%** 다(짝지은 t 2.63~3.81,
   모두 유의). 절대값으로는 E/P IC 0.0997→0.0926, B/M 0.0747→0.0555. B 가 쓰는 가격의 중앙 나이는
   **273일**이다. 기말가 고정은 팩터를 죽이지는 않지만(랭크상관 0.90~0.97) 잃는 쪽이 체계적이고,
   **손실이 B/M 에서 E/P 의 3~4배**인 점이 실무적으로 중요하다 — v3 가 PBR 계열을 기말가로 쓰고
   있다면 그쪽부터 고쳐야 한다.
3. **C(선행)는 이 판으로 판단 불가**다. 이유는 IC 값이 나빠서가 아니라 ① `consensus_daily` wise
   축의 `available_date` 가 전부 2026-09 백필이라 **엄격 PIT 로는 가용 행 0건**이고, ② 완화 PIT 로
   풀어도 실질 이력이 2025-08 부터 13개 관측(FY1 은 6개월)뿐이기 때문이다. 같은 6/11개월 창에서
   C 가 A 보다 IC 가 0.007~0.021 높지만 그 창에서는 A 조차 t<1.6 이라 우열을 말할 수 없다.
   **C 판정은 wise 월말 스냅샷이 12~18개월 더 쌓인 뒤 다시 해야 한다.**

## 5. 한계

1. **`fin_std` 는 다판본 PIT 가 아니다.** `vintage_kind` 가 `api_restated` 단일값이고 키당 1행뿐이라,
   기준일에 보이는 숫자는 **나중에 재작성된 최종본**이다. `available_date`(=접수일) 로 "언제부터
   알 수 있었나"는 지켰지만 "그때 뭐라고 적혀 있었나"는 지키지 못했다. 재작성 편향만큼 A·B 의 IC 가
   과대평가돼 있을 수 있고, 이는 A·B 에 **공통으로** 작용하므로 3-2 의 A−B 차이는 상대적으로 덜 오염됐다.
2. **컨센서스 PIT 불가** — 4절 3번과 동일. C 수치는 전부 참고용이다.
3. **생존 편향은 거의 없지만 0은 아니다.** 다음 월말 `adj_close` 가 없어 제외된 행이 83,473 중 **17건**
   (0.02%)이다. 상장폐지 종목은 그 직전 월말까지는 유니버스에 정상적으로 포함된다.
4. **적자 종목 처리.** `A_ep < 0` 인 관측이 31.0% 다. Rank IC 는 적자를 "가장 비싼" 쪽으로 몰아넣는데,
   이는 정의 그대로지만 실무에서 흔히 쓰는 "적자 제외" 또는 "E/P 를 양수만 랭크" 와는 다른 결과를 줄 수 있다.
   `A_bm < 0` 은 0.1% 로 무시 가능.
5. **거래비용·실행 미반영.** 월말 종가에 즉시 체결 가정. 회전율·슬리피지·호가 제약 없음.
   십분위 수익률은 동일가중 단순평균이며 섹터·시총 중립화를 하지 않았다 — 소형주 쪽으로 기울 수 있다
   (U2 결과가 그 완화판이고, U2 에서도 결론 방향은 같다).
6. **다중검정.** 8개 정의 × 2개 유니버스 = 16개 조합을 한 번에 쟀다. 사전등록이 아니라 서술적 프로브다.
   Bonferroni 임계 t(df 71, 양측 5%)는 16개 기준 **3.06**, A−B 짝지은 4개 기준 **2.563**이다.
   - IC 수준 16개 테스트: A·B 의 E/P·B/M 6개는 t 3.96~8.71 로 전부 통과, C 2개(t 1.3~2.0)는 탈락.
   - A−B 짝지은 4개 테스트: t 2.63 / 3.37 / 2.90 / 3.81 로 **4건 모두 통과**.
   즉 "A 가 B 보다 낫다"는 결론은 다중검정 보정 후에도 남는다.
7. **연결/별도 혼용.** CFS 우선, 없으면 OFS 로 대체했다(전체 중 OFS 20%). 소수주주지분 포함인
   `net_income`·`total_equity` 를 썼고 `net_income_owners`·`equity_owners` 는 결측이 각각 32%·26% 라 쓰지 않았다.
8. **비12월 결산.** 연간 `period_end` 중 454건이 비12월이다. A·B 는 `period_end` 기준으로 정상 처리되지만,
   C 는 `target_period` 를 12월기로만 매핑했으므로 비12월 결산사가 빠져 있다.
