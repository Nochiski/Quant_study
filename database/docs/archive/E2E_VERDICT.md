# 파이프라인 관통 테스트 — 최종 판정

**판정: 조건부 통과 (PASS WITH BLOCKERS).**
5단계(KRX → 샘플 → 키움/KIS → 통합)가 전 구간 관통했고 원장 149,161행 → 통합 66,127행이 무결성 검사를 전부 통과했다.
그러나 **DART 단계가 실행되지 않았고**(예측표 1행 전체 미검증), **통합 원장에 은닉 오염 424행이 플래그 없이 적재**되어 있다. 백필 착수 전 아래 BLOCKER 2건 해소 필요.

검증 방식: 최종 응답 텍스트를 믿지 않고 `e2e/*.db` 를 직접 SQL 조회해 재확인했다. **추가 API 콜 0.**

### ★ 어긋남 1 (최대 수확) — ka10014 공매도가 2010년까지 내려간다. 계획서의 "2019-06-17 하한 확정"은 틀렸다

예측은 A·B 모두 "없음"이었다. 실측은 **둘 다 있음, 그것도 전량 실데이터**다.

```
ka10014 window×값 분포 (kiwoom.db)
window  rows  tickers  shrts_zero  shrts_nonzero  min_dt    max_dt
A        67      7          0            67       20100104  20100115
B       105     11          0           105       20180402  20180413
C       124     15          0           124       20260807  20260820
```

0-패딩이 아니라는 3중 근거 (실측):

1. **`shrts_qty` 0행이 A구간 67행 중 0건.** 패딩이면 0이 섞인다.
2. **KRX·KIS 와 3자 교차 일치.** `005930` 20100115 → 키움 `shrts_qty=16492`, KIS `ssts_cntg_qty=16492`, 키움 `close_pric=+842000` = KRX `TDD_CLSPRC=842000` = 키움 `trde_qty=398401` = KRX `ACC_TRDVOL=398401`. 네 소스가 같은 값을 가리킨다.
3. **전송 파라미터가 순수 6자리 티커.** `kw_raw/ka10014_000660_A.json` → `body: {"stk_cd":"000660","tm_tp":"1","strt_dt":"20100104","end_dt":"20100115"}`. 특수 접미사 없이 2010 데이터가 왔다.

> **미확인:** 계획서 R6-5 는 `ka10014` **`_AL` 접미사** 형태를 전제한다. 본 테스트는 **접미사 없는 순수 티커**로만 호출했다. `_AL` 이 다른 커버리지를 갖는지는 확인하지 않았다 — 백필 전 1콜 프로브 필요.

**이 한 칸이 R7(174,537콜)의 존재 이유를 무너뜨린다.** 아래 5절에서 정산한다.

### ★ 어긋남 3 (예측표에 칸조차 없던 것) — 폐지종목에서 **키움과 KIS 가 정반대로 동작**한다

예측표는 소스별 *시간축* 가용성만 물었다. 실측은 **종목축에 더 큰 구멍**이 있음을 드러냈다.

| | 키움 (종목축) | KIS (종목축) | KRX (날짜축) |
|---|---|---|---|
| 폐지 5종목 응답 | **60셀 전부 rc=0 + 0행** | **실데이터 반환** | **실데이터 반환** |
| `117930` 한진해운 | 12셀 0행 | **100행** (20161007~20170228, 비영 71) | 2010 10행 |
| 통합DB 잔존 행수 | `investor_flows` **0행** | `short_selling` 100행 | `daily_prices` 60행 |

KIS `depth/117930` 실측 발췌 — 상장폐지 직전 정리매매 구간까지 정상 반환:
```

20170228          100       61246423       7758
20170223          310      104049406     319400

**즉 생존편향은 "소스의 성질"이 아니라 "축의 성질"이다.** 날짜축(KRX)과 KIS 종목축은 폐지종목을 보존하고, **키움 종목축만 조용히 버린다.** 이건 예측표가 아예 묻지 않았던 차원이고, 백필 설계에 직접 영향을 준다(5절 R7 분할).

### ⬛ 어긋남 4 — DART 단계 미실행 (테스트의 구멍)

```
dart.db  = 0 bytes,  테이블 0개,  PRAGMA integrity_check = ok(빈 파일)
e2e/ 내 DART 스크립트 0개,  xform.py 내 'dart' 문자열 0회

## 4. 파이프라인 결함

### DEFECT-E01: KIS 커버리지 밖 응답이 `incomplete` 플래그 없이 통합 원장에 적재됨 — 은닉 오염 424행 **[BLOCKER-1]**

- **상황**: KIS 공매도 커버리지 시작(2008-06-23) 이전 구간을 조회한 원장 행이 `xform.py` 변환을 통과해 `equity_test.db:short_selling` 에 들어간 상태.
- **인풋**:
  1. `kis('/uapi/domestic-stock/v1/quotations/daily-short-sale','FHPST04830000', {FID_INPUT_ISCD:'005930', FID_INPUT_DATE_1:'19990101', FID_INPUT_DATE_2:'20010330'})` → `rt_cd=0`, `msg_cd=MCA00000`, output2 **100행 만행**
  2. 해당 원장(`kis.db:kis_daily_short_sale` tag=`ssdepth/2001`,`ssdepth/2006`,`ssbisect/20070330`)을 `python3 xform.py` 로 변환
- **에러 위치**: `/private/tmp/.../e2e/xform.py:212-223` — KIS 행 적재 루프. 특히 **`xform.py:221`** 이 모든 KIS 행에 `'ok', 1 if d in DATE2WIN else 0, 0, None` 을 **하드코딩**한다. 즉 `src_status='ok'`, `incomplete=0`, `incomplete_reason=NULL` 이 커버리지 경계 검사 없이 무조건 박힌다. `short_selling` 스키마(`xform.py:86-91`)에 `incomplete`/`incomplete_reason` 컬럼이 선언돼 있음에도 **KIS 경로에서는 한 번도 채워지지 않는다**.
- **위험성**: **silent corrupt.** 실측 검증 결과:
  ```sql
  SELECT COUNT(*) FROM short_selling
   WHERE src LIKE 'kis%' AND asof_date<'20080623' AND (incomplete=0 OR incomplete IS NULL);
  -- 424
  ```
  424행이 "공매도량 0" 으로 정상 데이터인 척 앉아 있다. 같은 행의 `close_prc`·`volume` 은 **진짜 실값**이라(px_real 100/100, vol_real 100/100) 눈으로도 스팟체크로도 안 걸린다. 이 원장으로 공매도비중 팩터를 만들면 **2000~2008년 전 구간 공매도비중 = 0** 이라는 존재하지 않는 시계열이 생성되고, "공매도 압력 없음 = 매수 신호" 류 팩터가 **역사상 가장 강한 가짜 시그널**을 그 구간에 만든다. 과제 지침의 "행수로 판정하라"가 **여기서는 무력하다** — 행수가 가득 차 있다.
- **재현**: `sqlite3 e2e/kis.db "SELECT tag,COUNT(*),SUM(CAST(ssts_cntg_qty AS INT)=0),SUM(CAST(acml_vol AS INT)<>0) FROM kis_daily_short_sale WHERE tag LIKE 'ssdepth%' GROUP BY 1;"` → `ssdepth/2001|100|100|100`
- **수정 방향**: `xform.py:221` 의 하드코딩 `0, None` 을 커버리지 경계 판정으로 교체 — `asof_date < '20080623'` 이면 `incomplete=1, incomplete_reason='pre_coverage_kis_shortsale'`. 값 기반 판정(전필드 0 + 가격/거래량은 실값)을 완결성 게이트에 추가.

### DEFECT-E02: KIS 가 액면분할을 분자/분모에 **비대칭 적용** — 공매도비중이 정확히 분할배수만큼 틀린다

- **상황**: 분할 이력이 있는 종목의 분할 이전 구간을 KIS `FHPST04830000` 으로 조회. `005930` 삼성전자(2018-05-04, 50:1)의 2010~2018 구간.
- **인풋**: `kis('/uapi/domestic-stock/v1/quotations/daily-short-sale','FHPST04830000',{FID_INPUT_ISCD:'005930', FID_INPUT_DATE_1:'20100104', FID_INPUT_DATE_2:'20100115'})`
- **에러 위치**: KIS 서버측 응답 생성. 관측 근거 `e2e/kis.db:kis_daily_short_sale` tag=`short/A/005930`. 통합 후 영향 지점은 `xform.py:219-220` — `g('acml_vol')` 과 `g('ssts_cntg_qty')` 를 **같은 행에서 그대로** 가져다 쓰므로 왜곡이 `short_selling.short_ratio` 로 전파된다.
- **위험성**: **분자는 미조정, 분모는 조정** 되어 비율이 1/50 로 축소된다. 3자 대조 실측:

  | 필드 | KIS | 키움 | KRX | 판정 |
  |---|---:|---:|---:|---|
  | 종가 | 16,840 | 842,000 | **842,000** | KIS 만 분할조정(÷50) |
  | 거래량 | 19,920,050 | 398,401 | **398,401** | KIS 만 분할조정(×50) |

## 7. 최종 판정

**조건부 통과.** 파이프라인은 관통했고 통합 계층의 무결성 검사(PIT·항등식·정합성)는 전부 통과했다. 그러나 백필 착수 전 다음 2건이 선행되어야 한다.

**BLOCKER-1** — `xform.py:221` 의 `incomplete` 하드코딩으로 은닉 오염 424행이 원장에 존재. 커버리지 경계 판정 추가 후 재변환.
**BLOCKER-2** — DART 미검증. 재무 축은 이 테스트가 아무것도 보증하지 않는다.

### 이 테스트가 실제로 산 것

계획서 대비 **−44,490콜(−14.7%)** 과 **26.75% 생존편향 제거**를 476콜로 샀다. 회수율 약 94배.

그보다 큰 수확은 **"성공 응답이 데이터의 존재를 뜻하지 않는다"** 가 3가지 독립된 형태로 실증된 것이다:

1. **0-패딩** (`ka20068` A구간): 만행수 + 전량 0
2. **은닉 제로필** (KIS 커버리지 밖): 만행수 + 가격·거래량은 실값 + 대상 필드만 0
3. **조용한 누락** (키움 폐지종목): rc=0 + 0행

**세 형태 모두 `rt_cd`/`return_code` 로는 잡히지 않고, 2번은 과제 지침의 "행수로 판정하라"로도 잡히지 않는다.** 완결성 판정은 반드시 **행수 + 값 분포 + 외부 소스 대조** 3층으로 가야 한다. DEFECT-E02(액면분할 비대칭)는 그중 **교차대조 층에서만** 검출됐다 — 단일 소스로는 영원히 안 보였을 오류다.
