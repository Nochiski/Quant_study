# 모델 엑셀 산출물 규격 (T2.5b 정본, 2026-09-26)

사용자 결정(09-25·26): 엑셀은 **값만(수식 없음)**, 점수 열과 표시용 열을 **시트로 분리**, **판단 시트는 두지 않는다**(09-26), 서식·열 문법은 삼성증권 Q.Pack(`docs/research/2026-09-26-samsung-qpack-structure.md`). 레지스트리 지표의 `role: score|display` 가 시트 배치를 결정한다. 모델·축이 늘면 열이 늘어난다.

## C. 디자인 — 삼성증권 Q.Pack 셀 단위 벤치마킹 (2026-09-26 실측)
| 요소 | Q.Pack 실측 | 우리 규격 |
|---|---|---|
| 격자선 | 시트 격자선 **끔** | 끔 |
| 글꼴 | 맑은 고딕 8, 데이터 행 기본 높이 11.25 | 동일 |
| 1행 | 정렬 마커 행(`sort`/`s`), 채움 테마 accent1 60% 밝게(연한 파랑), 가운데 정렬 | 동일(우리 정렬 키 표기) |
| 2~4행 제목 블록 | 시트명 굵게 + 기준일 셀, **accent1(파랑) 채움 띠**, 우측에 저자·연락처 | 시트명 · 모델/버전 · 기준일·Source·판 id, 같은 파랑 띠 |
| 6~7행 헤더 | 채움 흰색 50% 어둡게(회색 #7F7F7F), 6행 위·좌·우 얇은 테두리, 7행 좌·우·아래 얇은 테두리(열마다 상자), 7행 높이 33.75·줄바꿈, 가운데·위 정렬. 핵심 그룹(Sector 시트 Index)은 accent4(금색) 채움·굵게 | 동일. 종합·순위 그룹만 금색 |
| 데이터 행 | 채움 없음, 위 정렬, `#,##0` / `#,##0.0` / `#,##0.00`, 코드 `A005930` 문자 | 동일, 코드는 6자리 문자 |
| 열 너비 | 식별 5~15, 숫자 열 **13.0 고정**, 그룹 사이에 너비 5의 **빈 구분 열**(숨김·아웃라인 1) | 동일 — 그룹 구분 열로 그룹 경계 표시 |
| 틀고정·필터 | 식별+첫 그룹까지(Company `Z8`), 7행 자동필터 | 식별 열 끝에서 고정, 7행 자동필터 |
| 색 스케일 | 3색 **백분위 10/50/90** 기준, 낮음 초록 63BE7B → 중간 노랑 FFEB84 → 높음 **빨강 F8696B**(한국 관행: 빨강 = 상승·높음). 변화율·변화 열 블록에만 | 동일 팔레트·백분위 기준. 백분위·변화율 열은 높음=빨강; **순위 열은 반전**(1위=빨강). 레벨 값 무색 |
| Style 시트 | 헤더 진파랑 0070C0 + 굵은 테두리, 항목명 보라 글씨 | 업종 시트 헤더에만 적용 |
| 시트 순서 | 시장→…→종목(Company)→실적 | 점수 → 점수 원자료 → 지표 → 실적 → 업종 → 모델 비교 → 메타 |

## D. 공통 서식
1행 정렬 마커 · 2~4행 제목 블록(시트명 / 모델·버전 / 기준일·Source·판 id) · 6~7행 2단 헤더 · 8행부터 데이터 · 식별 열까지 틀고정 · 헤더 행 자동필터 · 맑은 고딕 8 · `#,##0.0` · 병합 없음. 색 스케일(63BE7B–FFEB84–F8696B, 초록=좋음)은 백분위·순위 변화·변화율 열에만, 레벨 값 무색. 형광은 "신규 진입" 한 종류. 순위는 1 = 최고. 결측은 "결측(사유)" 문자열. 동일 지표를 두 시트에 중복 표기하지 않는다.
