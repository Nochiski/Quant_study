```
2008 ─── 공매도
2010 ─── 가격·시가총액·거래량·업종 · 투자자수급 · 외국인보유
2011 ─── 대차잔고
2015 ─── 재무 전계정 (DART API 하한. 이 벽은 못 넘는다)
2022 ─── 카엘 EPS·컨센서스
2024 ─── 지분 변동 (롤링 2년이라 과거로 못 간다)
```

**백테스트 시작을 언제로 잡느냐가 팩터 집합을 결정한다.**
2010년부터 돌리면 가격·수급 팩터만, 2015년부터면 재무가 붙고, 2022년부터면 컨센서스까지 쓴다.

> **경계 연도(2021/2022)에 가짜 점프**가 생긴다. 합치기 전에 중첩 구간(2022~2025)을 대조할 것.
