- **취득 원리적 불가는 5개뿐**이다: 공매도 **잔고** · 지수 **구성종목 PIT 이력** · **종목별** 프로그램매매 차익/비차익 분리 · 과거 시점 **이익 컨센서스** 스냅샷 · **KOSPI 관리종목 지정 이력**. 나머지는 전부 비용 문제다.
- **소멸성(오늘 시작 안 하면 영구 손실)은 3종뿐**이다: ① KIS `estimate-perform` 컨센서스 스냅샷 ② 키움 `ka10099` 상태(관리·정지·정리매매) ③ `payload_digest`/`revisions` 정정 관측. 나머지 "소급 불가" 주장은 실측으로 뒤집혔다(§10).

**우선순위 정의**
- **P0** = 없으면 계산 결과가 **조용히 틀린다**(silent corrupt / look-ahead / 부호 반전). 부재보다 나쁘다.
- **P1** = 없으면 특정 팩터군·평가축이 계산 **불가**. 값이 틀리지는 않는다.
- **P2** = 있으면 축이 하나 늘어난다. 없어도 기존 팩터가 죽지 않는다.
- **P3** = 넣지 않는다(소비 0, 파생 가능, 또는 원리적 취득 불가).

**카엘v3 소비** — ● 직접 소비(코드가 이 테이블/컬럼을 SELECT) · ○ 파생 소비(카엘 산출물의 입력) · − 미소비
