> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 매 거래일 19:00까지 그날 장마감 데이터로 멀티팩터 스코어를 내고 텔레그램으로 보고한다. 다음 날 아침 KRX 공식 데이터로 확정판을 만든다. 정착 후 kael-system-v3 의 20:05 체인은 종료한다.

**Tech Stack:** v1 과 동일 — Python 3.12 · sqlite3 · duckdb · bash/cron(UTC) · flock · 텔레그램. 서버 `kael-server:~/quant-ledger`.
