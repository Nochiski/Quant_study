# 모델 엑셀 산출물 규격 (T2.5b 정본, 2026-09-26)

사용자 결정(09-25·26): 엑셀은 **값만(수식 없음)**, 점수 열과 표시용 열을 **시트로 분리**, **판단 시트는 두지 않는다**(09-26), 서식·열 문법은 삼성증권 Q.Pack(`docs/research/2026-09-26-samsung-qpack-structure.md`). 레지스트리 지표의 `role: score|display` 가 시트 배치를 결정한다. 모델·축이 늘면 열이 늘어난다.

## D. 공통 서식
1행 정렬 마커 · 2~4행 제목 블록(시트명 / 모델·버전 / 기준일·Source·판 id) · 6~7행 2단 헤더 · 8행부터 데이터 · 식별 열까지 틀고정 · 헤더 행 자동필터 · 맑은 고딕 8 · `#,##0.0` · 병합 없음. 색 스케일(백분위 10/50/90 — 빨강 F8696B · 노랑 FFEB84 · 초록 63BE7B, **초록 = 높음 = 좋음**(N-15). 순위 열은 1위 = 초록, 엔진이 '낮을수록 좋은' 지표는 미리 뒤집어 백분위도 높을수록 좋다)은 백분위·순위 변화·변화율 열에만, 레벨 값 무색. 형광은 "신규 진입" 한 종류. 순위는 1 = 최고. 결측은 "결측(사유)" 문자열. 동일 지표를 두 시트에 중복 표기하지 않는다.

## E. 부호 전환 플래그와 튀는 값 처리 (사용자 09-26)
| 대상 | 플래그(문자 열, 숫자 열 옆) | 숫자 처리 |
|---|---|---|
| 실적 y-y(매출·영업이익·순이익, 연간·분기) | **표식 열 없음** — y-y 칸 안에 풀어 쓴 글자: **흑자전환**(−→+ · 0→+) · **적자전환**(+→− · 0→−) · **적자지속**(−→−). 흑자지속은 숫자(N-19, 10-06) | 부호가 바뀌면 증가율 대신 그 글자를 같은 y-y 칸에 넣는다(Q.Pack 은 ±100 으로 클리핑) |
| 리비전 변화율(영업이익·순이익 1m·3m) | v3 규약 유지: **흑전·적전·적확**(적자 확대)·**적축**(적자 축소) | 이전값 ≤ 0 이면 변화율 대신 플래그. 숫자 열은 1/99 백분위로 윈저라이즈해 색 스케일이 튀지 않게 |
| 밸류 E/P·B/M | **적자**(순이익 < 0) · **자본잠식**(자본 ≤ 0) | E/P 는 음수 그대로 순위에 넣되 표시는 플래그 병기. PER 은 표시용 열에서만, 적자면 "적자" 문자 |
| 배당수익률 | 무배당은 0(결측 아님) | — |
| 색 스케일 | 백분위 10/50/90 기준이라 극단값의 영향은 작지만, 표시 열은 위 윈저라이즈 값을 쓴다 | — |

결측과 플래그는 다르다: 결측 = 데이터가 없음("결측(사유)"), 플래그 = 데이터가 있고 부호가 바뀜.
